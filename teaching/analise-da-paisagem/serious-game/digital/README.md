# RISK OF LANDSCAPES — Versão Digital

Esta pasta contém **dois caminhos paralelos** para digitalizar o serious game
*Risk of Landscapes*:

| Pasta | Para quê | Esforço | Quando usar |
|---|---|---|---|
| [`tabletop-simulator/`](tabletop-simulator/) | Pilotar o jogo online **na próxima turma** sem programar | 1 tarde | Validar regras, balanceamento e tempo com alunos |
| [`boardgame-io/`](boardgame-io/) | Web app multiplayer hospedado no seu domínio | Projeto de IC/extensão | Versão 1.0 pública (CC-BY) + coleta de telemetria pedagógica |

## Roadmap (alinhado ao plano em 4 etapas)

1. **Próximas 2 semanas** → `tabletop-simulator/` → pilotar com 1 turma.
2. **Coleta de feedback** → formulário Google (modelo `atividade_07.json`), perguntas
   sobre clareza de regras, balanceamento, tempo médio de partida e engajamento.
3. **Submissão de projeto** (IC/extensão) → entregar `boardgame-io/` a um(a) bolsista
   de Computação/Sistemas. O GDD completo está em
   [`../Guia_Risk_of_Landscapes_Westeros.md`](../Guia_Risk_of_Landscapes_Westeros.md).
4. **Versão 1.0 web** (CC-BY) → produto técnico + artigo de educação +
   replicação para outras disciplinas (Geotecnologias, Geotêxteis).

## Fonte única de verdade

Ambos os caminhos consomem o mesmo CSV de cartas:
[`../Cartas_de_Territorio_Paisagens_de_Westeros.csv`](../Cartas_de_Territorio_Paisagens_de_Westeros.csv)

> ⚠️ O CSV atual tem **20 territórios**; o guia menciona 24. Antes de avançar para
> a versão web, completar as 4 cartas faltantes (Castle Black, Hardhome, Last Hearth,
> Karhold/Barrowlands) para fechar as 11 macro-regiões.
